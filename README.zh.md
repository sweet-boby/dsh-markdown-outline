# dsh-markdown-outline

[English](README.md) | 中文

为 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 提供飞书文档式的 Markdown 目录：把 AI 回复中的 Markdown 标题整理成左侧独立分栏的可折叠目录树，支持同时检索标题与回复正文（包括尚未分页加载到浏览器里的历史轮次）、将多选章节作为原生 `@` 引用胶囊芯片随消息发送并点击查看详情，以及零污染、可随时恢复地隐藏任意对话轮次。

## 功能

- **整段会话目录。** 标题来自宿主侧对完整会话日志折叠出的投影，滚出已加载窗口的回复依然在目录里；点击时会按需翻页加载对应历史。
- **独立分栏。** 目录挤压对话区而不是浮在正文之上，可收成细条触发器，也可拖动调整宽度（180–420 px），两个选择都按浏览器记忆。
- **标题检索。** 命中的标题留在原层级，父级标题以浅色面包屑保留，命中处不丢失章节上下文。
- **正文检索。** 段落、列表项、引用块、表格与代码围栏都会命中并给出高亮摘要，思考过程块跳过。已加载轮次在浏览器即时检索，更早的未加载轮次经鉴权路由在宿主侧检索。
- **段落级跳转。** 结果滚动到命中的具体块，而不只是所在章节；跳转前会展开折叠祖先并按需翻页，落点短暂高亮。
- **多选引用与原生 `@` 胶囊芯片。** 打开多选、勾选章节或无标题轮次，再点**确认附加**（或在输入框直接键入 `@` 搜索章节）：
  - 在输入框中直接插入原生的原子引用芯片（`ReferenceChipNode`），并在输入框上方显示引用卡片（发送消息后自动收起）；
  - 发送后，聊天气泡内同样渲染为可点击的引用胶囊，点击输入框内或已发送消息中的胶囊即可在右侧详情栏查看该章节完整内容（包括未加载的历史轮次）；
  - 宿主侧在 `agent/pre-step` 阶段自动将引用芯片展开为结构化的 `recall` 上下文消息发送给大模型。
- **隐藏与恢复轮次。** 勾选不再想展示或给模型看的轮次并隐藏，它们会从目录栏、聊天区和模型提示词上下文中消失，同时保留在目录下方的折叠列表里，随时可以一键恢复（完全可逆，且不在聊天区产生任何多余消息）。
- **从已选轮次创建新会话。** 在多选模式下勾选需要的任意轮次（支持跨轮次非连续勾选），点击**新建会话**即可在当前工作区创建一个只包含所选轮次完整对话历史的新会话并自动跳转。
- **跟随主题。** 只使用 `--dsw-alias-*` 设计令牌，深色与浅色主题下无需独立配色。

## 安装

本包是一个 profile bundle。装进你使用的 profile，然后刷新页面：

```sh
dsh plugin --profile web add github:sweet-boby/dsh-markdown-outline
```

也可以直接从本仓库安装：

```sh
dsh plugin --profile web add git+https://github.com/sweet-boby/dsh-markdown-outline.git
```

bundle 会向 profile patch 插入一行 `md-outline`，卸载本包时该行一并移除。

## 运行要求

- DSH 0.2 及以上，Web 或桌面端。
- 宿主侧注册 `mdOutline` 会话投影、`agent/pre-step` 引用展开器、`GET /md-outline/search` 与 `GET /md-outline/section` 检索路由，以及 `POST /md-outline/hide`、`POST /md-outline/restore`、`POST /md-outline/fork-turns` 路由。

## 测试

```sh
npm test
```

测试跑在 Node 内置的测试运行器上，覆盖宿主侧章节提取、引用 URI 编解码与 `agent/pre-step` 展开、隐藏账本与投影折叠，以及客户端组件挂载、原子芯片派发与聊天区隐藏规则。
